# Multi-Agent-YouTube-Shorts-Generator
A multi-agent AI system designed to automate the creation of YouTube Shorts by coordinating specialized agents for script generation, content visualization, and formatting.

---

## 🚀 Overview
A multi-agent AI system designed to automate the creation of YouTube Shorts by coordinating specialized agents for script generation, content visualization, and formatting.

---

## 🧠 Problem
Creating short-form video content is time-consuming and involves multiple steps:
- Writing engaging scripts  
- Structuring content for short attention spans  
- Formatting for platform-specific delivery  

This system automates the workflow using **agent-based task delegation**.

---

## 🏗 Architecture
The system follows a multi-agent architecture where each agent is responsible for a specific stage of the content creation pipeline. A central workflow coordinates the agents, passing outputs from one stage to the next.

- **Script Writer Agent →** Generates short, engaging scripts  
- **Visualizer Agent →** Structures the script into visual scenes or segments  
- **Formatter Agent →** Optimizes the content for YouTube Shorts format  

---

## 🤖 Agents Explained

### ✍️ Script Writer Agent
- Generates concise, engaging scripts  
- Focuses on hook-based storytelling  
- Adapts tone for short-form content  

---

### 🎥 Visualizer Agent
- Breaks script into scene-wise structure  
- Suggests visual flow for each segment  
- Prepares content for video generation  

---

### 🧾 Formatter Agent
- Formats output for YouTube Shorts  
- Ensures timing, readability, and flow  
- Prepares final structured output
